# 默认登录与个人资料管理

## 账号体验

打开即可使用。云开发上下文提供当前微信身份，bootstrap 自动创建或恢复所属分区账号；不增加账号密码、手机号要求或登录授权弹窗。只有用户主动保存资料时才执行必要隐私授权。

新账号默认昵称为「薄肌学员」，默认头像使用应用自带的品牌人像图标。旧账号读取时按需补齐默认资料，不替换订单、训练、饮食或身体记录。

开发版账号资料保存在 test 集合与缓存；体验版、正式版共享 prod。头像也按分区和账号分配路径，不能把测试头像提交到正式账号。

## 页面

“我的”顶部展示头像、昵称与账号连接状态。点击进入“编辑资料”，使用微信原生 chooseAvatar 按钮、nickname 输入框和 form 提交。

- 选择头像仅本地预览，点击保存才上传；取消选择不改变原资料。
- 昵称去除首尾空白，支持 1～20 个 Unicode 字符，可重名；拒绝控制字符。
- 保存等待昵称的 nicknamereview 检查通过；未通过、超时或仍在检查时不提交。
- 输入框提交值会再次读取，避免微信昵称快捷填写后未失焦导致保存旧内容。
- 支持恢复默认头像；未保存返回需确认，取消编辑不会覆盖已保存资料。
- 离线时保留编辑页草稿，不显示保存成功；账号连接失败在“我的”提供重新连接。
- 旧基础库不支持头像、昵称或审核事件时提示更新微信，现有账号和训练仍可用。

## 云端数据与接口

账号文档新增 profile：nickname、avatarFileId、version、updatedAt。临时图片地址缓存在客户端展示层，不存入云端个人资料。

| 动作 | 输入与输出 |
|---|---|
| bootstrap | 返回 profile 与 profileEditingSupported，不需要额外 wx.login |
| profile.avatar.prepare | 接收 jpg/png，返回绑定当前账号、当前分区的上传路径、fileId、15 分钟有效凭据 |
| profile.update | nickname、baseVersion、requestId；可选头像凭据、fileId 或 resetAvatar；返回 saved/conflict 与最新资料 |

资料写入在事务中校验版本和请求幂等。头像先校验凭据及归属，再通过服务端临时链接有界读取校验 JPG/PNG 签名和 2 MB 上限，最后提交资料。只改昵称不上传文件。

并发保存返回资料版本冲突，由用户选择保留本机修改或云端资料；普通业务同步的过期响应不能回滚新保存的资料。客户端不会在保存时提交 userId 来决定身份。

## 头像存储与清理

永久文件前缀来自本环境实际云存储文件标识，配置在 server/stages.json；前缀不含密钥或临时访问链接。

路径为 test/avatars/<账号哈希>/<随机凭据>.jpg|png 或 prod 对应路径。准备上传时即记录预期 fileId，因此文件上传后即使未提交资料，仍可在凭据过期后清理。

替换后的旧头像进入 avatarGarbage 队列。删除失败保留队列，不改变保存结果；所属分区 reminderJob 在消息处理前执行文件清理，模板未配置或提醒关闭时也执行。只删除当前账号、当前分区的已登记文件，不删除正在使用的头像。

删除个人业务数据会恢复默认资料并清理现有头像和未提交上传；必要交易元数据继续按现有售后政策保留。文件删除失败由清理队列重试。

应在云控制台保持头像存储仅归属用户可写，禁止开放公共覆盖；不要通过直接编辑数据库绑定未登记头像。相同 AppID 的业务分区属于路由与数据隔离，不是客户端权限凭据。
