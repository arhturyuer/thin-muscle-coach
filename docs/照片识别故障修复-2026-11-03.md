# 照片识别失败排查与修复

**最新更正与成功验证：** 已改用支持图片且可抵扣成长计划额度的 deepseek-v4.1-flash，并通过官方云函数 SDK 完成真实识别。此前“赠送额度不支持照片识别”的结论有误；详见 [DeepSeek 图片识别接入](DeepSeek图片识别接入-2026-11-03.md)。下文保留历史排查经过。


## 实际根因

已在测试小程序运行时用项目自带的餐食示意图复现，未使用用户私人照片、未保存虚构饮食记录。云函数正常接受请求，模型网关返回 HTTP 403，实际业务码为 `AI_MODEL_NOT_SUPPORTED`。目标 `hy-vision-2.0-instruct` 在当前环境未启用，属于模型开通／计费配置阻断，不是照片上传失败。

官方说明：[调用大模型服务的错误码](https://docs.cloudbase.net/http-api/ai-model/call-llm)、[Agent 开发最佳实践的模型开通说明](https://docs.cloudbase.net/practices/agent-best-practice)。

## 已完成的代码修复

- 区分模型未启用、认证失败、额度不可用、参数错误、网络失败、超时、截断和结果格式错误，不再吞掉成一个通用提示。
- 测试接口 `setup.mealDiagnostic` 返回最近一次脱敏诊断。只保留类型、HTTP 状态、允许列表内的模型错误码与原因标签，不输出照片、提示正文或密钥。
- 请求声明准确的 Content-Length，结果支持 JSON 周围带说明文字；不修补截断 JSON、不执行回复内容。
- 新增“重试这张照片”。重试保留原照片与 requestId，使用相同的压缩图片字节，不需要再次拍摄、压缩或同意同一请求，避免重试时照片哈希变化或重复计次。
- 压缩图片仅在本机内存中短暂保留，最多三个请求；成功后释放，按账号、计划、日期和请求隔离。

启用视觉模型可能消耗模型额度或产生费用。尝试该配置变更时，自动审批拒绝了启用操作，理由是它属于持久云端配置变更，可能影响计费，诊断授权不包含开启模型。

未绕过审批、未改用其他入口启用模型、未购买资源或升级套餐。需用户明确授权模型启用范围；若平台要求新增付费或升级，先展示费用再确认。授权完成后需继续用真实模型验证识别结果。

## 授权后的额度核验

用户已授权“允许，仅使用现有额度”。只读检查套餐用量后确认：

- 当前环境为非资源点计费的个人版。
- 可用资源点资源包为 0。
- 存在 10 亿 Token 的小程序成长计划赠送包，以及 10 万张混元生图赠送包，均未使用。
- [成长计划官方说明](https://docs.cloudbase.net/ai/ai-inspire-plan-guide)明确赠送 Token 当前仅抵扣 hy4-preview、hy3、deepseek-v4.1-flash；这些额度不覆盖 hy-vision-2.0-instruct。
- [可用模型能力表](https://docs.cloudbase.net/ai/available-models)明确 hy4-preview、hy3 不支持图片，不能用文字模型伪装替代视觉识别。混元生图额度用于生成图片，不等于识别图片。
- 官方成长计划说明还注明 cloudbase 分组仅限资源点套餐；当前旧套餐不满足目标视觉模型的接入条件。因此“模型未启用”背后的根因是套餐／可用模型额度不匹配，不能仅切换客户端参数解决。

没有执行模型启用、套餐迁移、资源购买或充值。在用户仅允许现有额度的限制下，照片识别尚未恢复；重试及诊断代码已经更新测试版。需要额外授权和可用视觉模型资源后，才能继续真实模型验收。
