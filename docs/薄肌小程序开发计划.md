# 薄肌教练 · 首版开发计划与实现状态

品牌口号：**练得刚刚好，身材刚刚好，薄肌就是刚刚好。**

本文件替换初版“薄肌计划、免费内测、支付后置”的安排。

## 已确定的产品基线

成年居家运动新手，自重/弹力带，15/30 分钟。

**免费评估 → 个人计划与预期收获 → 9.9 元购买一轮 → 首训激活 → 今日训练与饮食任务 → 打卡 → 7 天成长报告。**

- 无自动续费，首次训练联网激活，按上海时区连续计算 7 个自然日。
- 付款待确认时恢复原订单；已购买有效挑战不能重复销售。
- 本轮结束保留历史，新偏好用于下一轮。退款走客服与平台流程，不设产品内自助退款按钮。
- 不承诺 7 天体型改变，不提供医学诊断、照片评估或自动热量处方。
- 训练、饮食、报告每天合并最多一条订阅消息，默认 20:00，默认关闭，用户主动订阅。

## 页面与设计

已实现今日、评估、计划预览/购买、训练、饮食、成长、报告、我的、订单、隐私 10 个页面。

暖白 `#F7F8F2`、墨绿 `#173E32`、薄荷绿 `#A9E4C2`；以大数字、留白、进度、任务列表组织内容，首页突出今日训练。

训练支持组次、休息计时、暂停、已有进度恢复、提前结束、难度与不适反馈。饮食提供每日任务、三餐简记与恢复日打卡。成长统计真实完成记录与可选测量，缺失数据不伪造为 0。

## 技术与云端接口

原生小程序 + 微信云开发；页面统一使用本地状态，`store + repository + syncService` 负责存储、计算与同步。

- 启动先呈现缓存，超过 5 分钟按需 bootstrap；游标支持增量记录读取。
- 每组训练只写本地，完成立即同步；其他修改 30 秒合并同步，离线保留队列。
- 操作 ID 去重；服务端验证版本，冲突保留本地草稿并由用户选择。
- 云端负责身份、订单、固定价格、付款确认、挑战激活、业务校验与提醒发送。
- `coach_test` / `coach_prod` 提供 bootstrap、sync.batch、purchase.create/status、challenge.activate、reminder.update、account.delete。
- `paymentCallback` 接收并验证加密 HTTP 支付事件；`reminderJob_test` / `reminderJob_prod` 每 5 分钟提醒调度与订单查单。
- 正式应用中不包含模拟支付服务或开发入口；测试替身仅在自动化测试目录。
- 采集受限的流程事件供内测分析：评估、购买、首训、完成/中断、饮食记录、报告、提醒开关。事件只含名称、时间与日期，不包含健康问卷和餐食正文。

## 验证与交付

自动化验证覆盖支付幂等、首训起算、退款撤权、日期边界、离线历史记录、同步冲突、账户隔离、删除、加密回调及付款确认完整闭环。WXML/WXSS 已使用本机微信编译器检查。

开发完成不等于真实服务已上线。支付能力与商品审核、云环境、密钥、订阅模板、正式审阅内容、授权视频及真机联调仍是发布前置条件。配置不足时保持真实购买关闭。

按单人开发约 20 个工作日、之后 14 个自然日内测估算；资格申请与审核等待单独计算。首轮观察评估完成率、支付转化、付款到首训、7 天执行和提醒关闭率，再决定 28 天计划等扩展。

实际部署步骤、环境变量、容量边界、回退及逐项真机验收见 [部署与验收](部署与验收.md)。

同一云环境内按部署包、集合、本机缓存与定时任务分区。开发版连接 test，体验版/正式版连接 prod；两边均允许真实支付及消息联调。共享支付回调验签后按订单号确定唯一分区。部署必须指定目标，详细命令和回退见 [测试与正式隔离](测试与正式隔离.md)。
