# 薄肌教练

**练得刚刚好，身材刚刚好，薄肌就是刚刚好。**

面向成年居家运动新手的中文微信小程序。理解薄肌 → 五组评估 → 个性化方案预览 → 月／年／三年指导服务 → 每日饮食训练 → 每周复评。套餐 ¥19／¥198／¥298，手动续购，均含 AI 每天 30 次成功回复。旧 ¥9.90 七天订单按原规则保留。

## 当前实现

- 使用原生 tabBar、navigator、form、radio-group、checkbox-group、switch、picker、progress、video、icon 和微信客服。
- 原生订阅授权、隐私授权、通知设置、操作面板、退出训练提示与版本更新提示。
- 页面读取本地缓存，本地完成计时与统计，30 秒合并写入、完成训练即时同步，离线保留记录。
- 订单、金额、付费确认、挑战权益、消息发送由云端处理。
- 正式应用不包含模拟支付服务或开发入口。测试替身仅存在于 `tests/fixtures/`，不会进入小程序包。

新版实现与部署门槛见 [个性化指导改造](docs/个性化指导改造.md)。本地源代码已升级，以下历史部署记录不表示新版已经部署或开通收款。

使用微信开发者工具导入当前目录，入口为 `pages/today/index`。未配置云环境时可查看中文页面及填写本地草稿；购买和云端服务不开放，不会产生扣款。

已在 `miniprogram/core/config.js` 配置云环境 `cloud1-d2glj4fu92e8f1497`。个人主体版本不展示额外运营信息栏，咨询通过原生微信客服处理。支付密钥仅设置在云函数环境变量中。

```sh
npm run prepare:cloud
npm run check
npm test
npm run release:check
```

`check` 检查 JavaScript、JSON、路由和共享代码一致性；本机安装微信工具时同时编译 WXML/WXSS。`release:check` 额外检查云环境配置、原生导航图标和开发代码残留，缺少信息时明确失败。

修改 `shared/` 或 `server/` 后须重新运行 `prepare:cloud`，生成两个业务函数、两个定时任务及共享 `paymentCallback`。部署必须明确选择 `test`、`prod` 或 `callback`，上传时安装云函数依赖。

## 同云环境的测试与正式分区

开发版自动调用 `coach_test`；体验版和正式版调用 `coach_prod`，都使用 `cloud1-d2glj4fu92e8f1497`。数据库、缓存、订单和定时任务按分区隔离；两边都可在资格和配置就绪后真实支付、真实推送。

```sh
sh uploadCloudFunction.sh test --dry-run
sh uploadCloudFunction.sh prod --dry-run
sh uploadCloudFunction.sh callback --dry-run
```

去掉 `--dry-run` 后按指定目标上传，需先设置官方 CLI 路径。具体集合、变量、回调路由、切换和回退见 [测试与正式隔离](docs/测试与正式隔离.md)。
